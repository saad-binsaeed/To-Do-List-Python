# 📝 To-Do-List

A simple command-line To-Do List application built with Python. This project allows users to add, remove, and view tasks through an interactive menu-driven interface.

## 🚀 Features

* Add new tasks to the list
* Remove existing tasks
* Display all current tasks
* Simple and user-friendly interface
* Error handling for invalid inputs
* Menu-driven program flow

## ▶️ Getting Started

### Prerequisites

Make sure Python 3 is installed on your computer.

Check your Python version:

```bash
python --version
```

### Running the Project

1. Clone the repository:

```bash
git clone https://github.com/your-username/To-Do-List.git
```

2. Navigate to the project folder:

```bash
cd To-Do-List
```

3. Run the program:

```bash
python To-Do-List.py
```

## 📋 Menu Options

When you run the program, you will see:

```text
-----------TO DO LIST------------
1. Add a Task
2. Remove a Task
3. Show the Tasks
4. Exit
```

### 1️⃣ Add a Task

Allows users to enter and save a new task.

### 2️⃣ Remove a Task

Allows users to delete a task from the list by entering its task number.

### 3️⃣ Show the Tasks

Displays all tasks currently stored in the list.

### 4️⃣ Exit

Closes the application.
